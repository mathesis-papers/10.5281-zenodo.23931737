# 参与数学与形式化

以下共享请求协调技术章节中的准确范围。坐标族结果已有私有检查证明，该任务要求稳定公开接口与无序子集桥接。原实数正交单位、正权重定理不需要重复证明请求。

- [带符号上界](https://github.com/the-omega-institute/trureturing-requests/issues/117)
- [公开坐标族比较](https://github.com/the-omega-institute/trureturing-requests/issues/118)
- [Hermitian 复数比较](https://github.com/the-omega-institute/trureturing-requests/issues/119)
- [带符号双侧界](https://github.com/the-omega-institute/trureturing-requests/issues/120)
- [任意外次数多次提升](https://github.com/the-omega-institute/trureturing-requests/issues/121)
- [常权重等号与锐性](https://github.com/the-omega-institute/trureturing-requests/issues/122)
- [距离指数](https://github.com/the-omega-institute/trureturing-requests/issues/123)

先读对应陈述与证明，再在同一个规范请求中说明拟完成的准确条款。在自己的贡献者 fork 中建立聚焦分支，按[上游 trureturing `dev` 贡献规则](https://github.com/the-omega-institute/trureturing/blob/dev/docs/CONTRIBUTING.md)直接提交 PR，遵守既有准入、评审和 CI。保留原论文作者及前人的数学归属，并从 PR 链接同一个请求；不要求先合入 Mathesis fork。

上游合入并冻结后，先比较完整陈述，再更新证据引用。只形式化特例时，较广条款继续保留。GitHub 请求、CI 或合并与独立的 Mathesis 验证回执不同，不产生平台积分。[Mathesis 公开贡献入口](https://mathesis-omega-research.apps.chrono-ai.fun/contribute)说明单独的回执流程。

维护讲解时，保持中英文章节顺序、结果属性、证明与媒体引用对齐。运行已安装的论文一致性检查及 `./tbook check`。渲染沿用 Beamer 与 book-film 接口；正式视频渲染前以实测旁白时间轴替换估计，并在出版前查看两种语言及实际可播放的视频。
